# Fridgey

**한국어** | [English](README.en.md)

냉장고 재료와 유통기한을 **급한 순서대로** 보여 주고, 장보기 목록까지 한 곳에서 관리하는 무료 웹앱입니다.
설치도 회원가입도 없이 링크만 열면 되고, 함께 사는 사람과 **같은 냉장고를 같이** 볼 수 있습니다.

### 👉 [지금 열기: hong3007.github.io/Fridgey](https://hong3007.github.io/Fridgey/)

## 이런 점이 좋아요

- **입력이 빠릅니다.** 음식명과 날짜(`261020` = 26년 10월 20일)만 적고 엔터. 자주 쓴 이름은 자동완성(초성 검색 지원)으로 한 번에 추가됩니다.
- **급한 것부터 보입니다.** 유통기한이 가까운 순으로 정렬되고, 남은 일수가 색으로 표시됩니다.
- **장보기 목록**이 있습니다. 수량을 정하고, 사 온 것을 체크하면 한 번에 냉장고로 옮길 수 있습니다.
- **함께 쓸 수 있습니다.** 키 파일을 나눠 가진 사람끼리 같은 냉장고를 봅니다. 한쪽이 바꾸면 상대 화면에 보통 30초 안에 반영됩니다.
- **내 취향대로.** 구역(1층·2층…)과 앱·탭·입력칸·버튼 이름을 바꿀 수 있고, 테마는 5가지, 언어는 설정에서 **한국어·영어**를 고를 수 있습니다.
- **실수해도 괜찮습니다.** 다 먹은 재료는 "처리"하면 음쓰통(음식물 쓰레기통)으로 가고, 되돌릴 수 있습니다.

## 시작하기

1. 위 링크를 엽니다.
2. 처음에 나오는 **키 파일 보관 화면**에서 키 파일을 보관합니다. (카카오톡 "나에게 보내기"를 추천합니다.)
3. 음식명과 날짜를 넣고 **추가**.

함께 쓰려면 보관한 키 파일을 상대에게 보내세요. 받은 사람은 링크를 열고 "**이미 받은 키 파일이 있어요 (참여하기)**"를 누르면 같은 냉장고가 열립니다.

### 홈 화면에 추가

- **아이폰**: Edge로 열어서 메뉴(공유)의 **홈 화면에 추가**, 또는 카카오톡 대화방에서 링크를 눌러 바로 열 수 있습니다.
- **안드로이드**: Chrome 메뉴의 **홈 화면에 추가**(또는 **앱 설치**).

> 브라우저마다 저장 공간이 따로라서, 다른 브라우저로 처음 열면 새 냉장고가 따로 시작됩니다. 이어 쓰려면 키 파일로 참여하세요.

## 내 데이터는 어떻게 보관되나요?

- 입력한 내용은 **내 폰 안에서 암호화**된 뒤 서버(무료 보관 서비스 [Supabase](https://supabase.com))에 백업됩니다.
- 서버에는 **알아볼 수 없는 글자(암호문)만** 저장됩니다. 열쇠인 **키 파일은 서버에 올라가지 않습니다.** 서버 관리자도 재료 이름을 볼 수 없습니다.
- **키 파일을 가진 사람은 누구나**(키 파일을 보관한 메신저·클라우드 계정에 접근할 수 있는 사람 포함) 내용을 보고 고칠 수 있습니다. 보낼 때 받는 사람을 확인하세요.
- 냉장고마다 열쇠가 따로라서, 앱 링크를 아는 다른 사람이 자기 냉장고를 만들어도 서로 섞이지 않습니다.
- 이 저장소(GitHub)에는 **앱 코드만** 있고, 사용자 데이터는 없습니다.

## 알아 두세요

- **키 파일과 기기에 저장된 키를 모두 잃으면 복구할 수 없습니다.** 만든 사람도 열 수 없는 구조입니다.
- 브라우저의 쿠키·사이트 데이터를 지우면 폰에 있던 키도 지워집니다. 보관해 둔 키 파일로 **키 파일로 참여하기**를 하면 되살아납니다.
- 재료와 장보기는 각각 300개, 음쓰통은 최근 100개까지입니다.
- 무료 서비스를 쓰기 때문에 서버가 일시정지되면 다시 켜질 때까지 동기화가 멈춥니다. 그동안에도 각 폰에서는 계속 쓸 수 있습니다. 설정의 **데이터 내보내기**로 파일 백업도 가능합니다(내보낸 파일은 암호화되지 않으니 보관 위치에 주의하세요).

## 기술 구성 (궁금한 분만)

- 빌드 없이 **`index.html` 파일 하나**로 동작합니다. 외부 라이브러리는 쓰지 않고, 글꼴(Gowun Dodum)만 Google Fonts에서 불러옵니다.
- 배포는 GitHub Pages입니다.
- 암호화는 브라우저 내장 WebCrypto(AES-GCM)를 쓰고, 키에서 방 번호와 암호 열쇠를 따로 만듭니다. 서버에는 방 번호와 암호문만 있고, 서버 표는 직접 읽거나 쓸 수 없게 막혀 있으며 읽기·쓰기 함수 두 개만 열려 있습니다.
- 서버 쪽 설정은 저장소가 아니라 앱 제작자가 따로 관리합니다.
